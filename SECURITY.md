# Security Policy

## Scope

This is a **data/documentation repository** — a structured registry of negative results in AI collaboration. It has no runtime application, no user authentication, no API endpoints, and no secrets management.

Security concerns relevant to this project are limited to:

- **CI/CD integrity** — unexpected behavior in `.github/workflows/ci.yml`
- **Malicious submissions** — pull requests containing harmful content disguised as entries
- **Dependency vulnerabilities** — the sole Python dependency is `jsonschema` (used only in CI and maintainer-local validation)

## Reporting a Vulnerability

If you discover a security issue, please **open a GitHub Issue** with the label `security`. For sensitive matters that shouldn't be public, email the repository owner directly.

Please include:
- A description of the issue
- Steps to reproduce (if applicable)
- The affected file(s) or workflow(s)

## What Is NOT a Security Issue

- Data quality problems (incorrect fields, broken links, schema violations) → use a regular Issue
- Classification/taxonomy disagreements → use a regular Issue
- Missing or outdated translations → use a regular Issue
- General questions or suggestions → use a regular Issue

## Supported Versions

Not applicable — this is a living registry with a single `main` branch. All entries and tooling are maintained on the latest commit.
