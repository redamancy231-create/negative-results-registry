## 预注册锚点

本项目预注册判据（`CLAUDE.md`「PoC 决策表」+ `PLAN.md` §九）：
- **端到端加速比 ≥5×**（相对最佳免费替代，同数据同 mask 同语义，含 H2D 传输与归并）→ 目标线
- **≥2×** → 最低可接受（PASS）
- **<2×** → STOP（负结果）
- **未达 ≥5× 目标线 → 记负结果 NRR**（标签 `NRR-2026-024`）

## 原始假设 `hypothesis`

预注册（CLAUDE.md PoC 决策表：NRR 阈值 ≥5×、最低可接受 ≥2×）：在 RTX 4060 Laptop GPU（sm_89）上，fc 加速器（pybind11 + CUDA 绑定，binding 级含传输）于固定 `corpus_synth_v1`（T=1218 × N=5000 × F=12）最小参数扫描流水（parameter_scan → 逐因子 rolling_ic → factor_corr + IC 归并，verdict_scope 排除 stock_corr）相对最佳免费替代（qgplearn 未安装 → min(numpy 2.4.4, cupy 14.1.1)，同数据同 mask 同语义，含 H2D 传输与归并）端到端加速比 ≥5×。

## 方法 `method`

预注册锚点：CLAUDE.md PoC 决策表（≥5× NRR 阈值 / ≥2× 最低）与 PLAN.md §九。

**端到端（主判据）**：`benchmarks/poc4_e2e_v1.py` + `benchmarks/phase4_bench_v1.py`——最小参数扫描流水，GPU 臂 pybind11 绑定（`factor_cuda_pybind`/`factor_corr_pybind`），numpy/cupy 臂 `benchmarks/backends.py`，对称 reps + Phase 4 fresh 轮（**臂序轮转 + untimed warmup + 热采样 + bootstrap CI**），`best_free=min(numpy,cupy)` 运行时记录，`verdict_scope` 排除 stock_corr。**统一估计量 = ratio-of-medians（min(med(numpy),med(cupy))/med(gpu)，与 committed poc4 一致）**；**决策统计量 = worst-case min-of-run-medians**。

**单算子（产品层补充）**：`phase4_bench_v1.py` binding 级 vs numpy/cupy，median + bootstrap CI，warm 3 + 20 采样（原样持久化）；适配层开销单独测量。

**复现性**：双 corpus 经 `corpus_loader_v1.py` 校验 data_sha256（fail-closed）；流水两 run 输出哈希逐位相等；G6 证据 self-hash 实门（**fail-closed 非零退出**）；git HEAD 钉扎 + **gate provenance envelope（绑 producer commit）**；corpus_real_v1（N=93）仅正确性 + 确定性锚点。**经 GPT-5.6-Sol 独立审查（13 发现）修复后 fresh 重出证。**

## 预期结果 `expected_result`

假设成立：F=12 端到端加速比 ≥5×（相对 best-free，含传输与归并）；单算子 ≥2×。预注册失败判据：<2× → STOP；≥2× 且 <5× → 记负结果 NRR-2026-024。

## 实际结果 `actual_result`

**E2E F=12 端到端加速比 2.895–3.035×**（fresh 轮统一估计量 **2.895×**；committed `poc4_e2e_v1.json` 3.035×；跨 run delta 4.6% 稳定，ratio-of-medians 估计量）。≥2× 最低可接受达成（PASS-partial），**≥5× 预注册目标未达成（假设被证伪）**。

**单算子（binding 级含传输，corpus_synth_v1 全量，vs best-free）**：factor_corr **13.15×**（≥5×，binding 级）；其余本轮 cs_rank 1.59× / parameter_scan 2.28× / rolling_ic 1.99× / stock_corr general 2.31–2.65×。

> **⚠️ 跨会话方差**：单算子中位数跨会话波动显著（如 rolling_ic 观测 1.99×→6.94×、cs_rank 1.59×→3.11×）。**不声称"除 factor_corr 外全部 <5×"**（rolling_ic 跨会话可超 5×）；单算子边界断言仅指示性，预注册决策仅依稳健的 E2E。

**组件级负结果（显式暴露）**：e2e 分操作 `ic_stack`（IC 归并）~0.72× 劣于基线，不埋入聚合 ≥2× PASS。

**适配层开销**：factor_corr 适配器相对裸绑定 **+238%**（1112.7ms vs 329.2ms，契约强制 f32→f64 Python upcast）。**不声称具体产品层 speedup**——适配层与 best-free 来自不同测量块，机械组合无结构化依据。

## 效果量 `effect_size`

E2E F=12 speedup 2.895–3.035×（预注册目标 5×，达成 ~58%；≥2× 下限达成；统一估计量 ratio-of-medians；决策=worst-case min-of-run-medians）。factor_corr 13.15×（binding 级，≥5× 例外）；其余单算子 1.59–2.65×（本轮），跨会话 1.59–6.94×（波动，指示性）。

## 样本 `sample_size`

corpus_synth_v1：T=1218 × N=5000 × F=12。e2e F∈{4,8,12} reps + fresh 轮（6 samples/arm，臂序轮转 + untimed warmup）+ bootstrap CI；单算子 warm 3 + 20 采样（原样持久化）+ bootstrap CI。corpus_real_v1：T=1212 × N=93 × F=3（仅正确性/确定性）。qgplearn 未安装 → best-free=min(numpy,cupy)。

## 涉及模型/工具 `models_used`

DeepSeek-V4-Flash (via Claude Code CLI)；OpenAI gpt-5.6-sol (via Codex CLI，独立审查)；CUDA 13.3；pybind11；numpy 2.4.4；cupy 14.1.1；RTX 4060 Laptop GPU。

## 为什么失败 / 解读 `interpretation`

预注册 ≥5× 端到端目标未达成（2.9–3.0×），≥2× 最低可接受达成。归因**分机制、均标注为候选而非已证实**：

1. **FP64 硬件天花板**（候选机制，未做 FP32 聚合路径的确认实验）：RTX 4060 Laptop FP64 ≈ FP32/64 可能限制 float64 聚合操作（rolling_ic/factor_corr 一般归约/stock_corr general）的加速上限；但同证据集 **factor_corr（float64）达 13.15×**，削弱天花板为主因的强度。
2. **launch/传输/占用开销**（候选机制）：解释 float32 操作与产品层传输成本。
3. **阳性对照（binding 级）证明内核可达 ≥5×**：factor_corr 13.15×（同 corpus_synth_v1 非退化面板），below_5x 是负载/层相关而非普遍内核低效。
4. **层差异披露（非因果）**：acceptance kernel-resident 与当前 binding 含传输来自不同会话/基线，仅披露层差异，不作"kernel 高估用户侧"的因果声明（跨会话方向不稳）。
5. **适配层 Python 开销**：fc 适配器契约强制 f32→f64 Python upcast（factor_corr +238%），为产品优化机会非绑定缺陷；不机械组合产品层 speedup。

**跨会话方差**：单算子中位数波动大（rolling_ic 1.99→6.94×），单算子边界断言不作决策依据，决策仅依 E2E（稳定）。未验证的替代解释（更高 FP64 吞吐 GPU、FP32 聚合路径、kernel 调优）标为**未验证假设**。结论限定于 RTX 4060 Laptop + 固定 corpus + 排除 stock_corr 的 E2E 口径，不推广至其他 GPU 或 FP64 不占主导的工作负载。

## 可复现性 `reproducibility`

- **level**: `partially-reproducible`（同机同 commit 同 corpus → 输出位级确定性；计时跨会话/异机不可搬移）
- **artifacts_available**: code, data, logs, analysis-script, raw-output
- **notes**: corpus manifest 已提交（real data_sha256=FB23D9E1…8504F；synth 由 loader 运行时确认）；流水输出两 run 哈希逐位相等；G6 证据 self-hash 实门（11 源文件，fail-closed 非零退出）；gate provenance envelope（绑 producer commit）。qgplearn 基线臂未安装，best-free=min(numpy,cupy) 为替代，故 level 为 partially-reproducible（非 fully）。单算子跨会话方差已披露（1.59–6.94× 观测区间）。

## 相关阳性结果 `related_positive_result`

同证据集阳性对照（binding 级）：corpus_synth_v1 全量（非退化面板、同 corpus）上 factor_corr 13.15×（≥5× PASS）证明同一批内核可达 ≥5×，把 below_5x 隔离为负载/层相关而非普遍低效；**阳性对照限定 binding 级**（适配层有 Python upcast 开销）。stock_corr fast 路径（全有效退化-mask 合成面板特例）5–12× 须与 general 口径并排，不单独用作内核能力证据。

## 教训 `lessons_learned`

1. **预注册双阈值（≥2× 最低 / ≥5× 目标）使 2.9–3.0× 成为无歧义裁决**：下限达成、目标未达 → 如实记负，不得把已记录缺口包装为成功。
2. **消费级 GPU（RTX 40 系）性能方差大**——单算子加速比跨会话可波动数倍（rolling_ic 1.99→6.94×），预注册决策须基于稳健的端到端判据而非波动大的单算子边界。
3. **性能声明必须标注层与传输口径 + 统一估计量**：kernel-resident/binding 含传输/适配层三层口径不同；ratio-of-medians vs median-of-ratios 估计量给出不同数字（3.076 vs 2.895），须预注册唯一估计量。
4. **『≥5× 可达』须分机制锚定 + 阳性对照限定层**：binding 级 factor_corr 13.15× 证明内核可超 5×，但适配层 Python upcast 有真实开销（+238%），不机械组合产品层 speedup。
5. **E2E 判定口径运行前声明并沿用**（verdict_scope 排除 stock_corr）；组件级负结果（ic_stack 0.72×）显式暴露；benchmark 须臂序轮转 + untimed warmup + 热采样防偏置；门须 fail-closed 非零退出。
