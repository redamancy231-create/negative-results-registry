## 实验概述

### 原始假设

> 声明式 action routing（YAML/JSON 结构定义可选 action → 精确匹配）预期优于自然语言 routing（自然语言描述可选 action → 语义匹配），因为声明式格式减少了 LLM 对 action 语义的歧义解读空间。

### 方法

Prompt-TDD 对照实验设计（Pilot 阶段）：
- **实验组**：声明式 action routing prompt（YAML 结构定义 actions，严格匹配）
- **对照组**：自然语言 routing prompt（自然语言描述 actions，语义匹配）
- **任务**：Claude Code agent 在多步任务中自主选择 action（文件操作、搜索、执行等）
- **样本量**：Pilot 15 cases（实验设计阶段——Tier 0，未进入 Tier 1 推断统计）
- **评估**：路由准确率 + 任务完成率

### 预期结果

> 声明式 routing 应减少 action 选择错误率，预期路由准确率提升 ≥10%。

### 实际结果

Pilot 15 cases 中，两组路由准确率和任务完成率无显著差异。效应量不足以支持进入 Tier 1 全规模实验。

## 解读与反思

### 为什么会失败？

两个可能解释：
1. **LLM 已是足够好的语义路由器**——自然语言描述 action 时，LLM 的语义理解能力足以消除歧义，声明式格式带来的额外精度是冗余的
2. **Pilot 样本太小**——15 cases 可能不足以检测小效应。但 Pilot 的设计目标就是在低成本阶段判断是否值得投入全规模实验——答案是"不值得"

### 学到了什么？

1. **"格式=精度"的直觉假设不全对**——写代码时声明式 > 自然语言，但 LLM 作为语义引擎反而可能消化自然语言更自然
2. **Pilot 的价值在于止损**——15 cases 就判断了不进入 Tier 1，节省了 ~4h 实验执行 + ~2h 审查时间
3. **阴性 Pilot 也是成功**——A3 在方法论手册中被标记为"如何闭合无信号实验"的**反例案例**，这个教学价值比阳性结果更独特
4. **和 A2 之间的一致性值得注意但不等于领域级结论**——A2（n=24对照）和 A3（n=15 Pilot）在各自条件下均未检出差异，形成待检验的元假设；需预注册、多任务、充分功效的汇总研究才能做总体判断
