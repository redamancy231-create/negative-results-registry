## 实验概述

### 原始假设

> 将代码审查 prompt 按 prep（规范加载）/ exec（逐文件审查）/ post（交叉校验）三段结构化分段，预期能提升 GPT-5.5 在多文件代码审查中的发现质量——相比单段"全部规范+全部文件一起审"的基线 prompt。

### 方法

Prompt-TDD 对照实验设计：
- **实验组**：prep/exec/post 三段式 prompt（A2 变体）
- **对照组**：单段综合 prompt（A2 基线）
- **任务**：对同一代码库进行多文件审查，记录发现数量、严重程度、误报率
- **样本量**：n=24/臂
- **跨模型复现**：GPT-5.5 主实验 + Qwen3.7-Max 独立复现
- **评估**：双 LLM 异后端盲评（审查者不知哪组是实验组）

### 预期结果

> 三段式 prompt 应产生更多高质量发现、更少误报。预期效应量 d ≥ 0.3（小到中）。

### 实际结果

两组在发现数量、严重程度分布、误报率上均无显著差异。

| 指标 | 数值 |
|------|------|

## 解读与反思

### 为什么会失败？

最可能的解释是**任务类型决定了 prompt 变异的效应量上限**。代码审查是一个结构化判别任务——审查者按明确的规范逐条检查。在这种任务中，prompt 的"包装"（分段还是单段）对输出质量的影响远小于任务本身的约束力。换言之：当规范足够明确时，prompt 怎么写没那么重要。

### 学到了什么？

1. **结构化判别任务上 prompt 变异效应近零**——与开放式生成任务（翻译、写作）形成对比，后者 prompt 变异效应更大
2. **规范本身比 prompt 结构更重要**——把精力放在写好审查规范，而非 prompt 的段落组织
3. **阴性结果需要跨模型复现**——GPT-5.5 的零效应可能是单模型噪声，Qwen 复现确认了效应的确为零
4. **实验设计的"工程门/科学门"拆分有价值**——即使实验结果是阴性，实验结构本身是可复用的
5. **效应量预估应在实验前做 ceiling probe**——如果早知道结构化判别的天花板效应，可能不会对这个方向抱太大期望
